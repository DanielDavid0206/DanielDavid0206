# 🕒 Reloj Digital con Alarma – Python Tkinter

## 📌 Descripción del Proyecto
Este proyecto consiste en una aplicación de escritorio desarrollada en Python utilizando la librería Tkinter. 
El sistema muestra la hora y fecha en tiempo real e incorpora un sistema de alarma configurable por el usuario.

## 🚀 Funcionalidades
- Visualización de hora en tiempo real
- Cambio de formato 12h / 24h
- Cambio de idioma (Español / Inglés)
- Configuración de alarma (HH:MM)
- Activación y desactivación de alarma
- Notificación sonora cuando la alarma se activa
- Uso de multihilos para evitar bloqueos en la interfaz gráfica

## 🛠 Tecnologías Utilizadas
- Python 3
- Tkinter
- datetime
